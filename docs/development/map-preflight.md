# 地图采用前预检合同

状态：2026-10-26。现有单图载入的保护底座，不是已经接入的世界／局部导航。

## 顺序与保证

`loadMapFromProvider` 在同一整图 IO 租约内先执行 [保守离图确认](<D:/fmg-cn/dreammap/docs/development/load-departure.md>)，获准读取后才完成来源读取、解码、版本门禁、`preflightMapData` 和 `prepareDetachedMapSvg`。以上全部成功也不会自动替换；有当前图时仍需最终放弃点击，由同步采用门禁重检现场状态，才标记模型不稳定、发出 `map:replacing` 并采用目标。

- 预检只处理本次读取的记录和脱离活动页面的 SVG；不迁移、重建几何、访问布局或写入当前模型。
- 预检失败返回保留原错误的 `failed`；不调用采用，不发替换事件，不使旧保存目标失效，不把原模型改成不稳定。旧完成回调仍只调用一次，IO 租约照常释放。
- 准备好的唯一 SVG 根传给采用阶段；采用移动该根，不再次解析 SVG 字符串。拒绝脚本节点，避免改变旧 HTML 插入方式下脚本的激活语义。
- 这不是完整 schema、引用一致性、几何正确性、资源安全净化或渲染就绪保证。没有禁止或净化全部事件属性、外部链接、图片、iframe、object 等内容；不能将不受信任的 SVG 视为安全输入。
- 采用仍会改写全局 options／grid／pack／DOM。若迁移、几何、样式或渲染阶段出错，仍可能留下混合模型；现有保存隔离继续生效，不能保证无损回滚。`loaded` 也不等于所有异步资源及首帧完成。

## 所选检查

1. 基础格网具有正间距、正整数行列、有限二维点及边界、地形特征数组；必需格网向量的数目与点数一致。
2. packed 向量互相等长、数值有限；不把 options 中期望的点数当成实际点数，也不声称已证明它们与随后重建的几何数量相同。
3. 必需及实际消费的可选 JSON 具有最低容器形状；拦截直接解引用的空实体、字体、自由标签、路线、区域、冰层、测量、旅程、图层及顶点覆盖容器错误。不全面验证嵌套字段与对象间引用。
4. SVG 按浏览器 HTML 解析语义准备，要求唯一顶层 `svg#map` 和内部唯一 SVG `g#viewbox`，拒绝核心身份歧义及脚本。不强制所有旧图具有现代图层；保留无关重复 ID、HTML 实体与既有命名空间兼容。

## 旧档兼容边界

- 旧 pipe 设置／生物群系、旧图层槽位和命名库仍按实际版本门禁处理；不拿现代完整设置 schema 拒绝本来会迁移或回退的记录。
- 保留既有中性首 `0`；features／markets 的旧空洞、旧坏引用及可由既有流程修复的数据不统一升级成拒绝。
- CSV 逐项扫描有限性及长度，不先 split 出整组临时字符串数组，也不统一施加新 typed-array 值域。旧负值、浮点值和超范围值保留原有转换语义。
- 对 packing 实际使用的 grid feature 引用，按 `Uint16` 特征 ID 和 `Int8` 类型转换判断；只在实际会解引用的分支拦截缺失特征。
- 此合同不改写原文件；不是对任意年代、任意损坏存档都兼容的承诺。
