## 仅改变下一 seed 的查找起点

[地物标记](<D:/fmg-cn/dreammap/src/generators/features-generator.ts>)的 `markupGrid`／`markupPack` 每完成一个 feature，都从 `featureIds` 寻找最小的零槽。原实现每次从零开始；本次只为同一原生 `Uint16Array.indexOf` 传入**包含当前 `firstCell`** 的起点。队列、邻接顺序、面积累加、顶点追踪、海岸距离、湖岸及高度算法不变，不降低格网密度或删除模型／图层。

设当前 seed 为 `s`。进入本轮时，所有 `j < s` 槽非零；正文只写 seed 和原本为零的邻槽，故此前缀不会再出现零。正文若结束，从零或从 `s` 搜索得到的下一个最小零槽相同，逐轮保持相同 feature ID、队列操作及浮点运算顺序。下一 seed 不减；所有搜索累计扫描量由最坏 `O(F×N)` 降至 `O(N+F)`，额外空间 `O(1)`。此复杂度仅指 seed 搜索，不是整个地物算法。

- 必须包含 `s`，不能用 `s + 1`。`Uint16` 写入 ID 65536 会回绕为零；可完成的孤立分量可能再次选择同一 seed，须保留旧行为。
- 不修复 ID 溢出：某些同类有环分量在旧实现中可能不终止，本改动没有扩大 ID 类型或解决此限制。
- 空 pack 原 guard 保留。标准空 grid 原异常保留；不顺手给无效输入增加新语义。证明不覆盖敌意重入、篡改原生方法或带副作用的自定义输入。
- 普通文件载入会重建 packed graph 并调用 `markupPack`；`markupGrid` 主要用于生成／高度图重标记。方法级结果不能直接外推为总载入收益。
